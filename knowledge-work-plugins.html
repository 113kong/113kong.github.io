앤트로픽 직무별 플러그인 — 클로드에게 내 일을 매번 설명하지 않게 해 주는 공식 무료 플러그인

공개 준비 중 유튜브 숏츠 영상 보기 ↗

  • 앤트로픽이 직접 만들어 무료로 공개한 직무별 플러그인이에요(Apache-2.0, 깃허브 별 3만 6천 개 이상). 영업·마케팅·법무·재무·인사·고객지원·작은 가게까지 플러그인 17개에 일 기술이 181개 들어 있어요.
  • 클로드 데스크톱 앱의 코워크(Cowork)용으로 만들었고 클로드 코드에서도 돼요. 코워크에서는 claude.com/plugins에서 골라 설치해요.
  • 모두 글(마크다운·JSON)로 돼 있어서, 우리 회사 도구와 말에 맞게 고쳐 쓸 수 있어요.

설치

코워크

claude.com/plugins에서 productivity 설치

클로드 코드

claude plugin marketplace add anthropics/knowledge-work-plugins → claude plugin install productivity@knowledge-work-plugins

첫 명령

/productivity:start

쓰는 법

  1. 설치한 뒤 /productivity:start를 치면 할 일 목록, 기억 파일, 대시보드가 만들어져요.
  2. 클로드가 내 역할·팀·지금 우선순위를 물어요. 한 번 답해 두면 다음부터는 설명할 필요가 없어요.
  3. /productivity:update를 치면 오래된 할 일을 정리하고, 기억에 빠진 것을 물어봐요.

바로 쓰는 요청문

이번 주 할 일: 금요일까지 예산안 검토, 2분기 계획 초안, A사 견적 회신. 목록에 넣어 줘.
김 대리는 재무팀 김민수야. 주간 보고는 금요일 매출표를 말해. 기억해 둬.
오늘 아침 할 일 정리해 줘. 마감 지난 것부터.

메일·일정 훑기는 그 도구를 코워크에 연결해야 돼요. 회사 자료를 연결하기 전에 회사 보안 규정을 먼저 확인해요.
