키워드 「꿀팁」

토큰 낭비 방지 무조건 쓸 툴 5

영상에서 소개한 5개예요.

설치하는 법 (셋 중 하나)

1) 터미널에서 — 카드의 '설치' 칸을 복사해 붙여 넣으세요.

2) 클로드 코드 안에서 — /plugin 으로 시작하는 줄은 클로드 코드 입력창에 그대로 넣으세요.

3) 제일 쉬운 방법 — 클로드에게 링크를 주세요.

이 스킬 설치해 줘: https://github.com/저장소주소

설치가 끝나면 클로드 코드를 다시 열고 '이렇게 말해 보세요' 문장을 그대로 말하면 돼요.

01
그래피파이Graphify
코드를 지도로 만들어줘요
github.com/Graphify-Labs/graphify
 ↗
이렇게 말해 보세요
“우리 회사 프로젝트 전체 구조를 한눈에 파악할 수 있게 그래프로 분석해 줘.”
설치 (README 원문)
uv tool install graphifyy
graphify install
02
클로드멤claude-mem
세션 작업 내용을 압축 저장해요
github.com/thedotmack/claude-mem
 ↗
이렇게 말해 보세요
“지난주에 논의했던 고객 응대 가이드라인 내용 다시 불러와 줘.”
설치 (README 원문)
npx claude-mem install
03
옴니루트omni-route
여러 무료 모델을 자동 연결해요
github.com/diegosouzapw/OmniRoute/blob/main/docs/guides/CLI-INTEGRATIONS.md
 ↗
이렇게 말해 보세요
“비용이 가장 적게 드는 무료 모델로 전환해서 이 보고서 검토해 줘.”
설치 (README 원문)
npm install -g omniroute
claude mcp add-server omniroute --type http --url http://localhost:20128/api/mcp/stream
04
헤드룸headroom
입출력 데이터 크기를 압축해요
github.com/headroomlabs-ai/headroom
 ↗
이렇게 말해 보세요
“방대한 매출 데이터와 고객 로그를 압축해서 핵심 이슈만 찾아 줘.”
설치 (README 원문)
uv tool install --python 3.13 "headroom-ai[all]"
headroom wrap claude

github.com/QingYunA/answer-me-with-html

이렇게 말해 보세요
“이번 분기 신제품 제안서를 한눈에 들어오는 깔끔한 웹페이지 문서로 정리해 줘.”
설치 (README 원문)
/plugin marketplace add QingYunA/answer-me-with-html
/plugin install answer-me-with-html@answer-me-with-html
