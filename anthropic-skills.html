앤트로픽 공식 클로드 스킬 19개 — 한글 정리

2026-11-20 · 별 19.4만

  • 클로드를 만든 앤트로픽이 직접 공개한 스킬 저장소예요. 스킬 19개가 들어 있고, 깃허브 별이 19만 개를 넘었어요.
  • 영상에서 고른 다섯 개는 스킬 크리에이터·프런트엔드 디자인·웹앱 테스팅·MCP 빌더·문서 공동 작성이에요.
  • 클로드 코드에서 플러그인 명령 두 줄로 깔고, 쓸 때는 스킬 이름을 말하면 돼요.

설치

1. 마켓 추가

/plugin marketplace add anthropics/skills

2. 예시 스킬 설치(영상의 다섯 개 포함)

/plugin install example-skills@anthropic-agent-skills

3. 문서 스킬 설치(선택: 워드·엑셀·PPT·PDF)

/plugin install document-skills@anthropic-agent-skills

쓰는 법

  1. 클로드 코드 안에서 위 명령을 차례로 입력하고, 클로드 코드를 새로 열어요.
  2. "스킬 크리에이터로 영수증 정리 스킬 만들어 줘"처럼 스킬 이름을 넣어 말하면 그 스킬이 켜져요.
  3. 웹앱 테스팅은 내 컴퓨터에서 돌아가는 웹앱(localhost)을 Playwright로 열어 눌러 보고 스크린샷을 남겨요.

스킬 19개

  • skill-creator (스킬 크리에이터) — 원하는 기능을 말로 설명하면 나만의 스킬을 만들고, 고치고, 성능까지 재 봐요.
  • frontend-design (프런트엔드 디자인) — 흔한 AI 템플릿 티가 나지 않게 화면 방향·글꼴·배치를 먼저 정하고 만들어요.
  • webapp-testing (웹앱 테스팅) — Playwright로 내 웹앱을 열어 버튼을 눌러 보고 스크린샷·브라우저 로그를 남겨요.
  • mcp-builder (MCP 빌더) — 외부 서비스 API를 클로드에 잇는 MCP 서버를 Python·TypeScript로 만들어요.
  • doc-coauthoring (문서 공동 작성) — 기획서·제안서·기술 문서를 질문 → 초안 → 다듬기 단계로 함께 써요.
  • docx (워드) — 워드 문서를 만들고 읽고 고쳐요(목차·표·머리글 포함).
  • xlsx (엑셀) — 엑셀·CSV를 열어 고치고, 수식·차트가 든 표를 새로 만들어요.
  • pptx (파워포인트) — 발표 자료를 만들거나 기존 PPT 내용을 읽고 고쳐요.
  • pdf (PDF) — PDF 글·표 꺼내기, 합치기·나누기, 양식 채우기를 해요.
  • algorithmic-art (알고리즘 아트) — p5.js 코드로 생성형 그림(흐름장·입자)을 만들어요.
  • canvas-design (캔버스 디자인) — 포스터 같은 정지 그림을 PNG·PDF로 만들어요.
  • theme-factory (테마 공장) — 슬라이드·문서·랜딩 페이지에 미리 만든 테마 10개 중 하나를 입혀요.
  • brand-guidelines (브랜드 가이드) — 앤트로픽 공식 색·글꼴을 결과물에 입혀요(내 회사 버전을 만들 때 본보기).
  • internal-comms (사내 소통) — 주간 보고·공지·사내 뉴스레터를 회사 형식에 맞춰 써요.
  • slack-gif-creator (슬랙 GIF) — 슬랙에 맞는 크기·길이의 움직이는 GIF를 만들어요.
  • web-artifacts-builder (웹 아티팩트) — React·Tailwind로 여러 화면이 있는 claude.ai 아티팩트를 만들어요.
  • claude-api (클로드 API) — 클로드 API·SDK로 앱을 만들 때 모델 이름·요금·기능을 바로 찾아 줘요.
  • academy-guide (아카데미 안내) — 클로드 쓰는 법을 물으면 맞는 Claude Academy 강의를 골라 줘요.
  • discernment-nudge (한 번 더 생각) — 중요한 조언·초안을 준 뒤, 그대로 믿기 전에 확인할 점을 짚어 줘요.

앤트로픽은 이 저장소가 시연·학습용이라고 적었어요. 중요한 일에 쓰기 전에 내 환경에서 먼저 시험해 보세요. 라이선스는 Apache 2.0이에요.
