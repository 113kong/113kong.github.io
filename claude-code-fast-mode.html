클로드 코드 패스트 모드(/fast) — 켜는 법과 요금

공개 준비 중 유튜브 숏츠 영상 보기 ↗

  • 클로드 코드에서 /fast를 켜면 답을 쓰는 속도(토큰 생성)가 최대 2.5배 빨라져요. 2026년 11월 9일 Fable 5.2와 함께 나왔어요.
  • 쓸 수 있는 최신 모델은 Fable 5.2와 Opus 5.5예요. Sonnet·Haiku는 안 돼요.
  • 구독 한도에 들어가지 않고 사용 크레딧(usage credits)으로만 따로 내요. 요금은 기본의 두 배라 급할 때만 켜는 게 좋아요.

설치

클로드 코드 창에 입력해요

/fast

쓰는 법

  1. claude.ai/settings/usage에서 사용 크레딧(usage credits)을 켜요. 꺼져 있으면 /fast가 "Fast mode requires usage credits"라고 알려 줘요.
  2. 클로드 코드에서 /fast를 치고 스페이스로 켜고 엔터를 눌러요. "Fast mode ON"이 뜨고 ↯ 표시가 보이면 켜진 거예요.
  3. 급한 일이 끝나면 /fast를 다시 쳐서 꺼요. 설정 파일에 "fastMode": true를 적으면 늘 켜 둘 수 있지만 비용이 계속 나가요.

바로 쓰는 요청문

지금 대화에서 패스트 모드가 켜져 있는지, 켜져 있다면 이번 대화에 크레딧이 얼마나 나갔는지 알려 줘.
이 버그 하나만 빨리 고치고, 끝나면 패스트 모드를 끄라고 나한테 알려 줘.
긴 리팩터링을 시작하기 전에, 패스트 모드로 하는 게 나은지 기본으로 하는 게 나은지 비용 기준으로 판단해 줘.

Fable 5.2 패스트 모드는 클로드 코드 v2.1.321 이상이 필요해요. Team·Enterprise는 관리자가 먼저 켜야 해요. 대화 중 처음 켜면 그때까지의 대화 전체를 캐시 없이 다시 읽어서 첫 턴이 비싸요. Amazon Bedrock·Microsoft Foundry에서는 안 돼요.
