클로드 코드 영상 효과 51종 — /effects 한 줄로 릴스 편집

2026-11-16 · 별 924

  • 클로드 코드에 영상을 넣고 /effects 뒤에 효과 이름만 적으면 되는 무료 스킬이에요(MIT).
  • 효과는 51가지이고, 모두 얼굴을 따라가며 얼굴을 가릴 요소는 머리 뒤로 보내요.
  • 원본은 그대로 두고 효과를 입힌 파일(이름_effects.mp4)을 따로 만들어요.

설치

Mac·리눅스 (한 줄)

git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects

Windows PowerShell

git clone https://github.com/Vibha-Ramprakash/claude-video-effects $HOME\.claude\skills\effects

쓰는 법

  1. 설치 뒤 클로드 코드를 다시 열어요. 처음 한 번은 ffmpeg·파이썬을 스스로 설치하느라 2분쯤 걸려요.
  2. 영상을 채팅창에 끌어다 놓고 "/effects orbit 3초부터 6초까지"처럼 적어요.
  3. "내가 '불 꺼'라고 말할 때 spotlight"처럼 말로 시점을 정해도 되고, 효과 여러 개를 한 번에 겹쳐도 돼요.

  • noise — 내 릴스들이 머리 뒤로 쌓여요.
  • lineup — 번호 붙은 칸이 머리 위로 부채꼴로 펼쳐져요.
  • locked-on — 얼굴에 조준 괄호가 붙고 화면이 나를 따라가요.
  • orbit — 내 릴스들이 머리 주위를 돌아요. 위쪽은 머리 뒤로 지나가요.
  • lean-in — 한 단어에서 빠르게 확대돼요.
  • backdrop-word — 커다란 단어가 내 뒤로 떨어져요.
  • spotlight — 불을 끄고 나만 밝게 남겨요.
  • the-bill — 내 지시가 영수증처럼 인쇄돼 나와요.
  • moody — 분위기 있는 색보정을 입혀요.
  • swipe — 전후 비교 슬라이더가 지나가요.
  • todo — 머리 옆 체크리스트가 말하는 대로 하나씩 체크돼요.
  • comment-box — 인스타 댓글창에 글자가 쳐지고 게시돼요.
  • tap — 팔로우 버튼이 팔로잉으로 바뀌어요.
  • pause-point — 화면이 멈추고 손글씨 화살표가 나를 가리켜요.
  • uninstall — 지지직거리는 삭제 막대가 화면을 깨뜨려요.
  • reel-frame — 내 영상이 릴스 카드 안으로 줄어들어요.
  • shortcut-rain — 키보드 키가 내 뒤로 비처럼 떨어져요.
  • reject-stamp — 빨간 거절 도장이 쾅 찍혀요.
  • countdown-flip — 머리 위에 3·2·1 넘김 시계가 떠요.
  • rabbit-hole — 내 뒤 방이 터널처럼 멀어져요.
  • cover-star — 내가 잡지 표지가 돼요.
  • scribble — 마커 낙서가 내 주위에 저절로 그려져요.
  • glass-widgets — 반투명 유리 위젯이 머리 주위에 떠다녀요.
  • red-collage — 흑백의 나, 뒤에 커다란 빨간 단어, 세 줄 문구가 들어와요.
  • split-headline — 제목 카드가 내려오며 나를 아래 절반으로 밀어요.
  • pastel-word — 라벤더 방, 뒤에 큰 단어, 프로필 카드가 팔로우돼요.
  • check-pills — 모눈 방에 릴스가 붙고 파란 알약이 눌려요.
  • timeline — 붉은 필름 느낌에 편집 타임라인과 재생 막대가 지나가요.
  • headline-box — 확대되며 깔끔한 두 줄 제목이 붙어요.
  • profile-wall — 벽에 내 릴스 격자가 차고 숫자가 올라가요.
  • tier-list — 티어 표가 내려오고 클로드가 S티어로 날아가요.
  • broll-split — 위에는 B롤과 가격 스티커, 아래에는 내가 나와요.
  • phone-fan — 내 릴스가 휴대폰 카드처럼 부채꼴로 펼쳐져요.
  • dot-reveal — 빛나는 점들이 모여 내 화면이 되고 초점이 맞아요.
  • headline-wall — 머리 뒤로 기사 제목이 쌓이고 합계가 앞에 튀어나와요.
  • checklist — 턱 아래 클로드 작업 목록이 하나씩 초록으로 체크돼요.
  • liquid-glass-graph — 유리 카드 속 그래프가 오르고 숫자가 세어져요.
  • carousel-spin — 내 릴스가 3D 회전목마처럼 나를 돌아요.
  • match-cut — 한 단어에 맞춰 뉴스 지면이 머리 뒤에서 바뀌어요.
  • apple-toggles — 턱 아래 아이폰 스위치가 한 줄씩 켜져요.
  • led-sign — 불이 꺼지고 LED 간판 글씨가 내 뒤에 쳐져요.

  • over-the-shoulder-zoom — 한쪽 구석으로 확대돼 그래프가 뜨고, 반대쪽에서 또 하나가 떠요.

  • place-in-grid — 내가 3×3 프로필 격자 가운데로 줄어들고 조회수가 붙어요.

  • wave-trim — 목소리 파형에서 조용한 부분이 잘려 나가요.
  • huge-strike — 벽을 채운 큰 단어에 빨간 줄이 그어져요.
  • crayon-write — 빨간 크레용이 머리 뒤에 단어를 쓰고 밑줄을 그어요.
  • fan-build — 릴스 표지가 머리 뒤로 한 장씩 부채꼴로 깔려요.
